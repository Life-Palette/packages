拾色 (Life Palette) packages 是一组专注于**图片 / 视频素材处理**与**OSS 上传**的工具库。
所有逻辑跑在浏览器里，框架无关。

## 三个包

| 包 | 依赖 | 用途 |
| --- | --- | --- |
| [@life-palette/utils](./packages/utils/) | 零运行时依赖 | 纯函数工具集：异步 / 日期 / URL / 分页 / Markdown / 文件选择 |
| [@life-palette/media](./packages/media/) | exifr / blurhash / arthash / mediainfo.js / spark-md5 | 浏览器端媒体分析：主色、BlurHash、EXIF、视频元数据 |
| [@life-palette/uploader](./packages/uploader/) | `media` + browser-image-compression (optional) | OSS 上传：压缩 → 分析 → 并发分片（带重试） → 完成 → 实况照片关联 |

## 立刻开始

```bash
pnpm add @life-palette/utils @life-palette/media @life-palette/uploader
```

## 仓库结构

```
apps/
├── playground/   # 上传 + 分析测试台（Vue 3 + Vite）
└── docs/         # 本文档（Astro Starlight）
packages/
├── utils/        # 纯函数
├── media/        # 媒体分析
└── uploader/     # OSS 上传
```
