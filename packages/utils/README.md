# @life-palette/utils

Pure-function toolkit used across the Life Palette packages. Zero runtime dependencies — drop-in for any framework or runtime.

## Modules

- `async` — `sleep`, `debounce`, `throttle`
- `date` — `formatRelativeTime`, `formatDistanceToNow`
- `url` — `parseUrl`, `restoreUrl`, `isFastClick`
- `pagination` — `getPageNumbers`
- `markdown` — `stripMarkdown`
- `browser` — `selectFile`, `readFile`, `preloadImage`, `preloadImages`, `isSlowNetwork`, `getDeviceType`, `supportsWebP`

## Install

```bash
pnpm add @life-palette/utils
```
